# ProgressLab Project Overview

## 1. Problem Statement
    Individuals worign toward fitness goals may their fitness information scattered across different applications, notes, and tracking methods. This can make it difficult to maintain a consistent record of body measurements, workouts, fitness goals, and overall progress.
    ProgressLab will provide users a centralized system where they can record important fitness information and view their progress over time.

## 2. Intended User
    ProgressLab is intended for individuals who want to monitor and improve their personal fitness. Users may have different fitness goals, such as losing weight, gaining weight, improving body measurements, or maintaining consistent workout habits.

    Each user will create an individual account to access and manage their own fitness information.

## 3. Version 1 Scope

1. Users will be able to create individual accounts using an email address and password.

2. Registered users will be able to securely log in to their accounts.

3. Users will be able to create and manage personal fitness goals and monitor their progress toward those goals.

4. Users will be able to manually record their body weight and selected body measurements.

5. Users will be able to manually record workouts, including exercises, sets, repetitions, and weight used.

6. Users will be able to view a dashboard displaying information such as fitness goal progress, weight trends, workout activity, and other relevant progress information.

7. Users will be able to edit or delete previously entered fitness records when corrections are necessary.

8. The system will calculate a user's BMI using the information provided by the user and display the corresponding general BMI category.

## 4. Future Enhancements

1. Integration with wearable fitness devices, such as smartwatches, for automatic collection of workout and activity information.

2. Integration with external fitness and activity-tracking applications.

3. Nutrition and meal tracking.

4. Personalized workout, meal, or fitness recommendations based on a user's goals and recorded progress.

5. More advanced fitness analytics and progress reporting.
