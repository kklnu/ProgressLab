# ProgressLab UI Storyboard

## Screen 1: Landing Page

Purpose:
- Introduce ProgressLab.
- Allow a new user to create an account.
- Allow an existing user to log in.

Main Elements:
- ProgressLab logo/title
- Short description
- Create Account button
- Log In button


## Screen 2: Create Account

Purpose:
- Allow a new user to register.

Main Elements:
- Email field
- Password field
- Confirm password field
- Create Account button
- Validation/error message area
- Link to Log In


## Screen 3: Log In

Purpose:
- Allow an existing user to access their account.

Main Elements:
- Email field
- Password field
- Log In button
- Error message area
- Link to Create Account


## Screen 4: Dashboard

Purpose:
- Give the user an overview of current fitness progress.

Main Elements:
- Active fitness goal
- Goal progress
- Current weight
- Weight trend
- Workout activity
- BMI
- Navigation to Goals
- Navigation to Measurements
- Navigation to Workouts
- Log Out option


## Screen 5: Create Fitness Goal

Purpose:
- Allow the user to create a measurable fitness goal.

Main Elements:
- Goal type
- Starting value
- Target value
- Start date
- Target date
- Save Goal button
- Cancel option
